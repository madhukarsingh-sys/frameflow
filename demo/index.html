Frameflow

A photo gallery you add with one line. It loads more as you scroll, keeps only the photos near the screen in the page, and opens a viewer you can swipe, pinch and zoom.

<script src="frameflow.min.js"></script>
<div data-frameflow data-src="/photos?page={page}" data-height="70vh"></div>

0 of 480 photos loaded 0 in the page right now

Point it at your photos and it does the rest.

From a JSON endpoint

Use {page} in the URL for numbered pages, or return a next link or cursor. An empty page means the album is finished.

{
  "items": [
    { "src": "/p/lake.jpg", "w": 3000, "h": 2000,
      "alt": "Lake at dawn", "color": "#c86b6b" }
  ],
  "next": "/photos?cursor=8f2a"
}

From Firebase or any API

Pass a function instead of a URL. It gets the page number and the last cursor, and returns items.

new Frameflow('#album', {
  height: '70vh',
  source: async ({ cursor }) => {
    const r = await list(ref(storage, 'album'),
      { maxResults: 30, pageToken: cursor });
    return { items: await Promise.all(
      r.items.map(getDownloadURL)),
      next: r.nextPageToken };
  }
});

From plain HTML

Images already in the page become the first photos, so the album still shows if JavaScript fails to load.

<div data-frameflow>
  <a href="big/1.jpg">
    <img src="small/1.jpg" width="600"
         height="400" alt="Harbour">
  </a>
</div>
